Backup e restauração

Faça cópias independentes da carreira. O backup de dados guarda tudo o que você registrou. O backup completo guarda também o aplicativo, com todas as telas e funções como estão agora.

Dados (.json): partidas, elenco, escalação e formações criadas, base, planos, mercado, avisos, estatísticas corrigidas e o rascunho da partida. É um arquivo leve, ideal para guardar com frequência.

Completo (.html): o aplicativo exatamente como está no momento do backup, com todas as telas, comandos e os dados registrados. Ao abrir esse arquivo, ele já traz a carreira de volta.

Para restaurar: toque em Importar backup de dados e escolha o .json (ou um .html completo). A importação substitui os dados atuais.

No Android, o arquivo vai para a pasta Downloads. Se o download não começar sozinho, use o link que aparece acima e mantenha-o pressionado para salvar.
